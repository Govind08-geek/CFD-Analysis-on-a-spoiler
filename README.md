# CFD-Analysis-on-a-spoiler
Performed incompressible CFD simulation of flow around a GT spoiler using SimScale via Coursera/Rhyme. Configured external aerodynamics with velocity inlet, pressure outlet, walls &amp; symmetry BCs. Analyzed convergence of Ux, Uy, Uz, p, k, omega over 1000 iterations and visualized velocity-driven particle traces to study downforce generation.
